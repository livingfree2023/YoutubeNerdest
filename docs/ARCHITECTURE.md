# Architecture

`youtube-nerdest.user.js` is the installable source, without runtime dependencies, a backend or a build step.

- **Discovery:** one filtered document observer finds inserted/removed players and stats panels. Each panel has a content observer, which ignores its own controls.
- **Read path:** parse the native numeric Kbps text, divide by 1000 and round to whole Mbps. Display effective resolution from native stats, actual video dimensions or native effective-quality fallback. The effective badge is distinct from the requested quality mode. No network operations.
- **Presentation:** compact stats content is absolutely positioned at intrinsic width and hidden using `visibility:hidden`, keeping chart geometry measurable without contributing to the compact overlay's size. Expansion removes those overrides. Never use `display:none` on the stats content: YouTube's zero-height fallback resizes and clears canvases without resetting their drawing cursors. Original DOM, charts, positioning and close action survive.
- **Close control:** the same custom × stays anchored at the top-left in compact and expanded layouts. The native close button remains in the DOM for delegation, hidden while enhancement is active and restored if speed parsing fails.
- **Motion:** the chevron transitions by 180°. The Web Animations API animates measured panel width and height for 220 ms without writing native inline styles. Rapid reversals measure the current visible rectangle before canceling the prior effect. Reduced-motion preferences disable animation; absent animation support falls back to immediate changes.
- **Player actions:** access the actual page player via `unsafeWindow`; use its `showVideoInfo` method for auto-show. Custom close delegates to YouTube’s native close button, with `hideVideoInfo` as a fallback.
- **Quality shortcuts:** when expanded, intersect supported tier IDs with native `getAvailableQualityLevels()` and exclude explicitly unplayable quality-data entries. Request a fixed tier through `setPlaybackQualityRange(id,id)`; Auto requests `auto,auto`. Never use the modern no-op `setPlaybackQuality` export. Highlight native `getPreferredQuality()`, without claiming the effective resolution changed immediately. Check availability again before each click. The compact resolution badge cycles only available tiers from the highest down through 1080p, starting at the highest unless the effective or requested tier is already highest. Omit the expanded row if required APIs are unavailable.
- **Quality layout:** the script-owned row sits below native stats. A ResizeObserver drops optional 240p then 360p first when width is constrained; the selected optional tier stays accessible. Required choices can scroll on extremely narrow panels. Owned controls are excluded from mutation-driven rerenders; disposal disconnects resize observation and clears a bounded post-selection refresh timer.
- **Theme compatibility:** both compact and expanded badges inherit Enhancer's `--efyt-accent-color`, falling back to YouTube's `--yt-sys-color-baseline--static-brand-red` and then `#f03`. CSS inheritance tracks theme changes without any added observers, polling or requests. The variable was verified on the user's live themed page against the native badge and progress color.
- **Configuration:** Tampermonkey stores the `autoShowStats` boolean, default `true`; a menu command toggles it and a value listener propagates changes across tabs.
- **Lifecycle:** opening has at most 20 attempts spaced 500 ms apart, and stops when disabled, dismissed or opened. Video identity changes reset dismissal. Capture `loadedmetadata` and `yt-navigate-finish`; disconnect per-panel observers and player listeners on removal. Dispose observers and timers when leaving a non-cached page.

No standalone web app, service worker, deployment pipeline or compiled artifacts are involved. `dist/` is reserved and ignored if a build is added later. `node_modules/` contains development-only test dependencies.

The global baseline is supplied by the user and remains unmodified. Base feature decisions live in `specs/2026-10-23-compact-stats/`; motion refinements live in `specs/2026-10-23-animated-toggle/`; chart history in `specs/2026-10-23-chart-history/`; quality shortcuts and compact resolution in `specs/2026-10-23-resolution-switcher/` and `specs/2026-10-24-collapsed-quality-cycle/`.
